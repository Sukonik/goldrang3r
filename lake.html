Cluster · Morning edition

The VPN chain, closed

Ivanti has now patched every flaw in the Connect Secure chain Volexity found exploited in the wild: the October auth bypass plus a privilege escalation and a file-upload flaw, with fixed builds 25.1.1.3 and 22.8R2.6. CISA's KEV deadlines make the priority explicit — November 2 for the escalation flaw, November 13 for the upload flaw — and the lesson from the response post-mortems is to track the fixed version, not the CVE, since the advisory kept growing after the first patch.

  • SecurityWeek: Ivanti patches two more Connect Secure zero-days chained in attacks — CVE-2026-111357 (8.8) and CVE-2026-118527 — completing the chain with October's auth bypass, as CISA sets a November 2 federal deadline for the privilege-escalation flaw

BTCPay Server, built so no central party can pull the plug, had to ask every operator to pull it themselves: shut down with ./btcpay-down.sh until the investigation ends. Cluster · Morning edition

Your issue tracker is a shell

Eighty-three malicious issues, pull requests, and comments landed on 61 public repos in about 45 minutes on September 1, each hiding Bash command substitution in HTML comments. Where a workflow pasted user-controlled text into shell code, the payload ran env, encoded the output, and tried to POST it to an attacker server — with execution confirmed in at least two workflows. Radware confirms no stolen secrets or altered releases yet, but the pattern is the lesson: never let untrusted text reach a shell, quoted or not.

  • Cyber Security News: Radware traces a coordinated command-injection campaign that hit 61 public GitHub repos — LangExtract, Trivy, Brave, MLflow among them — hiding shell commands in issues and comments to run code inside Actions workflows and exfiltrate environment variables

Cluster · Morning edition

The viewer that trusts the server

TightVNC's viewer computes its framebuffer in 64 bits but stores it in a 32-bit int, so a server announcing 32768 x 32769 pixels gets a 128 KB buffer for 4 GB of pixels — and pixel writes then land at attacker-chosen offsets. A public PoC chains an ASLR leak and a ROP chain to CreateProcessW, before any password prompt, and Listening Mode on port 5500 needs no password at all. The fix shipped quietly in 2.8.89 and 2.8.90; upgrade to 2.8.90.

  • Cyber Security News: A pre-auth RCE in TightVNC Viewer 2.8.88 lets a malicious server execute code before any password prompt, via a 32-bit integer wrap that turns a 4 GB framebuffer into a 128 KB allocation; fixed in 2.8.89 and 2.8.90

Cluster · Afternoon summaries · Summary — Tech Security

The 10.0 that needs no key

Canonical's LXD and MicroCloud carry a maximum-severity flaw, CVE-2026-112816, that lets an attacker log in as a trusted client without holding that client's private key — only network access to the HTTPS API and the client's public certificate are needed. Fixed versions are out, but Canonical notes the LXD point releases were still rolling from the candidate channel to stable, so admins should check the version they actually have after refreshing rather than assume the fix arrived. The Incus project reports the same flaw and says restricting network access to the listener is the only mitigation short of upgrading to 7.6.0 — a reminder that a perfect score usually means the fix is urgent, not optional.

  • The Hacker News: Critical LXD and MicroCloud flaw lets attackers impersonate trusted clients without a private key

Cluster · Afternoon summaries · Summary — Tech Security

AI on both sides of the breach

Cisco Talos finds the VOLTA infostealer packaging stolen data into a structured bundle and handing it to an AI model to rank victims by their assets and security posture, with a fallback chain across Claude Opus 4.6, Kimi K2 and Gemini 2.5 Flash. On the other side of the same coin, CrowdStrike says China-backed Vapor Panda used an agentic AI pentesting tool to compromise 140 sensitive targets in 11 days. The same capability that sorts victims is now running the attacks — defenders should assume AI is in the loop on both sides of every incident from here on.

  • Precise Impact: VOLTA infostealer sends stolen data to an AI model to rank its victims
  • SecureResearch: Vapor Panda used an agentic AI pentesting tool against 140 targets in 11 days

Attribution lands, laundering moves

The FBI formally confirmed North Korea's TraderTraitor stole more than $6B from Binance and asked DeFi firms, exchanges and analytics providers to block 600-plus Ethereum addresses as the group converts the loot mainly into ether. The laundering has not paused for the announcement: on November 1 the attacker's wallet moved about 486,970 SOL, roughly $46.4M, toward Bitcoin through the Relay cross-chain service, part of a reported 970,522 SOL stash. Attribution names the culprit; it does not freeze the funds — the chase now runs through every swap service the group touches.

  • CoinDesk: FBI confirms North Korea's TraderTraitor stole more than $6B from Binance
  • TradingView News: Binance hacker routes stolen Solana through Relay Protocol

Cluster · Afternoon summaries · Summary — Fintech Security

Polymarket pays it back

A hijacked third-party page-speed script injected malicious code into Polymarket and drained about $2.7M from signed-in traders' wallets. The platform now says 689 of the 726 affected wallets have been refunded in full, with the rest paid as claims are verified, plus $1.19M to about 5,500 wallets for losses during the trading halt. Supply-chain attacks keep finding the weakest script on the page — and this time, at least, the refund math is public.

  • VerakWorld: Malicious code injected into Polymarket via a hijacked third-party script drains about $2.7M
  • Stocktwits: Polymarket says 689 of 726 wallets hit have been refunded in full

Cluster · Afternoon summaries · Summary — Fintech Security

The phone you can't patch

OneKey founder Yishi warns that iPhone 11 and earlier models carry unpatchable BootROM flaws — checkm8 and the June-disclosed usbliter8 — that could expose wallet seed phrases to anyone who briefly holds the phone and uses a DFU-mode USB tool. The flaw lives in the chip's boot ROM, so no software update can fix it; the defense is physical — keep older phones out of other people's hands and move wallet keys to newer hardware. For anyone still running a crypto wallet on a pre-12 iPhone, this is the nudge to migrate.

  • TradingView News: OneKey founder warns older iPhones have unpatchable chip vulnerabilities
