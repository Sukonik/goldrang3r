Root without a login, twice in one day

Two different boxes, the same nightmare: root access with no credentials at all. Barracuda's Email Security Gateway can be owned by chaining a 9.3 authorization bypass — which lets an unauthenticated attacker restore a crafted configuration backup — with an 8.6 command injection that runs as root; the patch shipped Monday and the gateway is fixed in version 9.4.0.030. Hours after the SSHole disclosure, attackers were already trying the oversized-password trick against Alpine Linux honeypots and got root in under nine hours, needing only a valid account name and a password between 257 and 1,024 characters. Both fixes exist; the race now is whether admins install them before the scanners find the exposed interfaces.

  • The Hacker News: Two Barracuda Email Security Gateway flaws chain to unauthenticated root — a 9.3 authorization bypass plus an 8.6 command injection
  • The Hacker News: Hackers target the SSHole OpenSSH flaw within hours of disclosure, gaining root on an Alpine Linux honeypot — the musl bypass needs only an oversized password

Cluster · Afternoon summaries · Summary — Tech Security

The browser extension that drives your AI agent

A browser extension that can run scripts on claude.ai could turn Claude Desktop into a remote shell, researchers at Forever Security showed: Dispatch accepted an ordinary signed-in web session, so an extension could send the desktop agent instructions as if the user had typed them — and auto-approve the prompts. Because Dispatch pairs devices by account, the same trick could reach a second computer, turning a personal browser add-on into a foothold on a work laptop. Anthropic accepted the report as valid in May but closed it as a duplicate, and says Dispatch is being retired — though the researchers warn the same trust model lives on in Claude Code Remote Control and Cowork sessions.

  • The Hacker News: Malicious browser extensions could use Claude Dispatch to run code on users' computers

Three stories from three very different corners, all about trust. DigiCert began notifying customers after a February 2025 migration left an internal system on the public internet for 16 months, exposing archived records — including passports and driver's licenses for a small minority — with no count disclosed. The heist, laundered in the open

The Binance laundering operation is now measurable: Elliptic counts more than 20,000 wallets across 16 blockchains and 65,000 transactions, with about $124M in stolen altcoins already swapped into bitcoin — most of it XRP moved through THORChain — while roughly $3.11B still sits in attacker-linked addresses and $2.85B has been frozen. Binance, meanwhile, is reopening withdrawals in stages and says it has replenished virtually all customer losses — the heist is becoming a long, public accounting exercise rather than a single event.

India's cyber agency warns the money pipes

India's CERT-In has warned banks, payment firms, and crypto exchanges about AI-driven attacks from a group it calls CRAFTY FALCON, which it rates critical: the attackers exploit payment and disbursement APIs to push through unauthorized transactions and steal wallet keys. The advisory, issued November 4, names non-bank lenders, digital lending platforms, payment aggregators, and virtual-asset exchanges among the targets, and urges firms to isolate affected systems, rotate credentials, and report incidents. The warning lands a week after the Binance heist showed what happens when the same playbook works — the industry's pipes, not just its vaults, are the target now.

  • Outlook Money: CERT-In cautions financial firms and crypto exchanges over AI-driven attacks by CRAFTY FALCON on payment APIs and wallet keys

SSHole, exploited within hours

The patch was barely a day old when attackers moved: Previdian saw the first SSHole exploitation attempt less than nine hours after disclosure and confirmed root access on an Alpine Linux honeypot, using oversized passwords against accounts with no usable password set. The flaw, CVE-2026-123158, hits OpenSSH on musl libc with PAM disabled — Alpine's default server configuration — and the fix is OpenSSH 10.6p2, with sshd restarted after patching.

  • The Hacker News: Hackers target the SSHole OpenSSH flaw within hours of disclosure, gaining root on an Alpine Linux honeypot — the musl bypass needs only an oversized password

DigiCert's 16-month lapse reaches customers

DigiCert has begun notifying customers after a February 2025 server migration moved an internal business system onto the public internet, where an unauthorized account read archived records between June 27 and July 2, 2026. The data includes names, business emails, phone numbers and addresses — and, for a small minority, passports, driver's licenses and utility bills. The company found the accounts in June, confirmed the access on October 19, and has not said how many people are affected; its certificate authority services were not touched.

  • The Register: DigiCert begins notifying customers after a 16-month lapse left archived records exposed — passports and driver's licenses among the data, with no count disclosed yet

Proxy exits on the White House network

Layer3 Intel found six IP addresses on AS2650, the network reserved for the Executive Office of the President, serving as residential proxy exits — used by 28 proxy services 236 times between October 5 and November 3, mostly in the evening hours. Synthient traces the traffic to Windows 11 machines running the Infatica SDK. The cause is unconfirmed and no breach is claimed: the finding rests on the address registration, not an identified device — but anyone signing up to a public proxy service could route traffic through the network.

  • SecurityWeek: Residential proxy exits found on the White House network — six addresses used by 28 services 236 times, with the cause unconfirmed

Cluster · Morning edition · Summary — Tech Security

A zero-day behind the switches, a 9.2 in the decoder

The Zyxel story gets a correction: the attacks on nearly 1,000 GS1900 switches, first blamed on a patched flaw exploited by a group tracked as Red Heron, actually ran on the newly disclosed zero-day CVE-2026-107441, Binarly finds — the June patch never stood a chance against a flaw nobody had named. And a second decoder-level flaw lands the same morning: Node2Shell, a CVSS 9.2 out-of-bounds write in Google’s Brotli library, can allow remote code execution wherever the decoder is bundled — Node.js, .NET, PowerShell, Git for Windows and more — and CISA already added it to its exploited list on October 27. Two flaws, one lesson: the vulnerable component is rarely the one you installed on purpose.

  • ThaiCERT: The Zyxel switch attacks first blamed on a patched flaw actually ran on the new zero-day, CVE-2026-107441, Binarly finds — hitting nearly 1,000 switches
  • Lemon Web: Node2Shell: a critical Brotli decoder flaw, CVE-2026-111497, rated CVSS 9.2, could allow remote code execution across Node.js, .NET and other platforms

The patch that didn't patch

Zyxel's June patch for its GS1900 switches never stopped the attack after all: Binarly found the exploit still worked against all ten firmware releases shipped as the fix, because it abused a previously unknown flaw, CVE-2026-107441, rather than the June bug — and the vendor has now shipped new firmware for the ten affected models. OpenSSH, meanwhile, issued an emergency fix for a flaw that let long passwords bypass authentication on Alpine Linux. Two patches in one day, and both carry the same warning: a fix only counts once it actually closes the hole it was meant to close.

  • The Hacker News: Zyxel's earlier GS1900 patch fails to block the zero-day exploit, Binarly finds, as the vendor ships new firmware for 10 switch models
  • The Hacker News: OpenSSH issues an emergency fix for a flaw letting long passwords bypass SSH auth on Alpine Linux

Cluster · Afternoon summaries · Summary — Tech Security

A 10.0 that needs no login

GitLab's maximum-severity flaw, CVE-2026-97229, lets an attacker with no account run code on a self-managed GitLab server by feeding a crafted regular expression into a CI/CD configuration file — an integer overflow in the regex compiler, rated 10.0. CISA added it to its exploited list on October 29 on evidence of active attacks, with a federal patch deadline of November 1 that has now passed, and scans still counted more than 1,000 internet-facing instances unpatched. Alpine Linux learned the lesson the hard way: its upgrade to a supposedly fixed version left the flaw open because the underlying Ruby fix was missing from its custom container image, forcing a full rebuild of its GitLab from scratch. The patch exists; the gap is whether the whole stack underneath it was actually updated.

  • SOCRadar: CISA confirms active exploitation of GitLab's maximum-severity CVE-2026-97229, and Alpine Linux rebuilds its GitLab after an exploitation attempt
