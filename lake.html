The heist’s long tail

Chainalysis’s account of its own breach keeps widening: a week after first saying only names and emails were taken, the firm now says password hashes and live tokens for all users were exposed, and every user must reset passwords and rotate API keys. Its KYT screening service restarts in phases on Friday while Reactor, the investigators’ tracing tool, stays offline. Meanwhile Chainalysis traces nearly $1B of the stolen Binance funds into laundering channels, about $500M of it routed through TRON across more than 1,000 addresses, and insurers tell Reuters the $6.3B heist will mean closer scrutiny of crypto firms at renewal — with no available policy able to cover a loss that size, and many excluding state-backed attacks outright.

  • CoinCentral: Chainalysis now says password hashes and live tokens for all users were exposed, a week after first saying only names and emails were taken — KYT restarts in phases, Reactor stays offline
  • The Cryptonomist: Chainalysis traces laundering of the stolen Binance funds to Chinese networks, with nearly $1B already moving — about $500M of it through TRON
  • Reuters: The $6.3B Binance heist is prompting insurers to scrutinize crypto firms’ security more closely, Reuters reports — no available policy could cover a loss that size

Cluster · Morning edition · Summary — Tech Security

A zero-day behind the switches, a 9.2 in the decoder

The Zyxel story gets a correction: the attacks on nearly 1,000 GS1900 switches, first blamed on a patched flaw exploited by a group tracked as Red Heron, actually ran on the newly disclosed zero-day CVE-2026-107441, Binarly finds — the June patch never stood a chance against a flaw nobody had named. And a second decoder-level flaw lands the same morning: Node2Shell, a CVSS 9.2 out-of-bounds write in Google’s Brotli library, can allow remote code execution wherever the decoder is bundled — Node.js, .NET, PowerShell, Git for Windows and more — and CISA already added it to its exploited list on October 27. Two flaws, one lesson: the vulnerable component is rarely the one you installed on purpose.

  • ThaiCERT: The Zyxel switch attacks first blamed on a patched flaw actually ran on the new zero-day, CVE-2026-107441, Binarly finds — hitting nearly 1,000 switches
  • Lemon Web: Node2Shell: a critical Brotli decoder flaw, CVE-2026-111497, rated CVSS 9.2, could allow remote code execution across Node.js, .NET and other platforms

Thursday, November 5, 2026

Cluster · Morning edition · Summary — Tech Security

The exploited list grows, from switches to phones

A zero-day Zyxel only just named, CVE-2026-107441, was the flaw actually behind the compromise of 996 GS1900 switches in 48 countries — the June patch never stopped it. CISA adds a WebKit flaw Apple patched 18 months ago, CVE-2024-27834, to its exploited list after Sekoia ties it to an APT29 watering-hole campaign serving exploit chains to visitors of compromised sites. OPSShield's cPGuard update-channel hijack keeps widening: about 2,950 servers ran the root-level backdoor and 7,900 billing records were taken. And OpenAI says one autonomous run produced 948 validated Linux kernel root exploits, each with a patch drafted, for $1.2M in API credits — with Reuters reporting the same AI acceleration on the attack side, from hacked supermarket fridges to the record Binance theft. The day's through-line is blunt: the flaw is already patched, the update channel is already trusted, and the exploit is already cheap — the gap is whether anyone acted on any of it.

  • BleepingComputer: Zyxel patches a GS1900 zero-day, CVE-2026-107441, that hackers used to compromise 996 switches in 48 countries and steal configs and hashed root passwords
  • The Hacker News: CISA adds a WebKit flaw Apple patched 18 months ago, CVE-2024-27834, to its exploited list after Sekoia ties it to an APT29 watering-hole campaign hitting unpatched iPhones and Androids
  • Abijita: OPSShield says a hijacked cPGuard update channel pushed a root-level backdoor to about 2,950 Linux hosting servers and exposed 7,900 billing records
  • GBHackers: OpenAI says an autonomous pipeline found and validated 948 Linux kernel root exploits — with a patch drafted for each — in a single $1.2M run
  • Reuters: AI is sharpening the cat-and-mouse hacking battle, from hacked supermarket fridges to a record Binance theft, as companies rush to strengthen defences

The heist, counted

Crédit Mutuel Arkéa now puts a number on this week's cyberattack: about €100M missing, with the bank unable to say yet how much it can recover. Cluster · Afternoon summaries · Summary — Tech Security

The patch that didn't patch

Zyxel's June patch for its GS1900 switches never stopped the attack after all: Binarly found the exploit still worked against all ten firmware releases shipped as the fix, because it abused a previously unknown flaw, CVE-2026-107441, rather than the June bug — and the vendor has now shipped new firmware for the ten affected models. OpenSSH, meanwhile, issued an emergency fix for a flaw that let long passwords bypass authentication on Alpine Linux. Two patches in one day, and both carry the same warning: a fix only counts once it actually closes the hole it was meant to close.

  • The Hacker News: Zyxel's earlier GS1900 patch fails to block the zero-day exploit, Binarly finds, as the vendor ships new firmware for 10 switch models
  • The Hacker News: OpenSSH issues an emergency fix for a flaw letting long passwords bypass SSH auth on Alpine Linux

Cluster · Afternoon summaries · Summary — Tech Security

A 10.0 that needs no login

GitLab's maximum-severity flaw, CVE-2026-97229, lets an attacker with no account run code on a self-managed GitLab server by feeding a crafted regular expression into a CI/CD configuration file — an integer overflow in the regex compiler, rated 10.0. CISA added it to its exploited list on October 29 on evidence of active attacks, with a federal patch deadline of November 1 that has now passed, and scans still counted more than 1,000 internet-facing instances unpatched. Alpine Linux learned the lesson the hard way: its upgrade to a supposedly fixed version left the flaw open because the underlying Ruby fix was missing from its custom container image, forcing a full rebuild of its GitLab from scratch. The patch exists; the gap is whether the whole stack underneath it was actually updated.

  • SOCRadar: CISA confirms active exploitation of GitLab's maximum-severity CVE-2026-97229, and Alpine Linux rebuilds its GitLab after an exploitation attempt

Cluster · Afternoon summaries · Summary — Fintech Security

After the heist, the regulators call

The $6.3B Binance heist is now a banking story: the Federal Reserve and the Office of the Comptroller of the Currency have been contacting US banks since Monday, asking about unusual activity and service disruptions, Reuters reports. Banks are running diagnostics to check whether the attack path that drained Binance could reach them, and within hours of the hack, security staff at one of the biggest US banks reached out to Binance directly. No US bank disruption has been reported — the calls are precautionary, but they show how fast a crypto exchange's worst day becomes every bank's checklist.

  • PYMNTS: US bank regulators checked in with banks after the $6.3B Binance heist, asking about unusual activity and disruptions, Reuters reports
