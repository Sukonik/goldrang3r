Tuesday, November 10, 2026

Cluster · Morning edition · Summary — Tech Security

Patch day, red alert

SAP’s November Patch Day lands four flaws at the maximum CVSS 10.0 — three in NetWeaver, one in Web Dispatcher — all exploitable by an unauthenticated attacker with no user interaction, and SAP urges customers to treat them as the first patch priority. Barracuda, meanwhile, says attackers have already started exploiting two recently patched Email Security Gateway flaws that chain into root access on the appliance, hitting a small number of customers. And N-able pulled its hosted N-central platform offline worldwide after a researcher published proof-of-concept exploits for 33 alleged zero-days, telling on-premises customers to shut their servers down until a hotfix ships. Three vendors, one morning, one message: the patch window is now.

  • The Hacker News: SAP patches four CVSS 10.0 flaws, including two enabling remote code execution — three hit NetWeaver and one the Web Dispatcher, all exploitable without logging in
  • BleepingComputer: Hackers now exploit critical Barracuda ESG flaws to gain root access — the two recently patched flaws, chained, let attackers run commands as root on the email gateway
  • The Hacker News: N-able takes N-central cloud offline after researcher discloses 33 zero-days with PoC exploits — the ‘Able2Shell’ chains reach remote code execution; no active exploitation seen yet

Cluster · Morning edition · Summary — Tech Security

State operations, named

ESET attributes a new modular .NET toolset, Cereal, to the Russia-aligned Turla group: it turns compromised Microsoft Exchange servers into email-collection points, and at a Romanian government agency it was set to harvest correspondence with NATO and EU addresses. On the same morning, France formally blamed an IRGC cyber unit, Shahid Kaveh, for the October attack that forced refrigeration controllers at about 700 retail sites into defrost, spoiling food and starting fires in at least 15 cases — Paris calls it the first cyber offensive campaign carried out purely for sabotage on French soil. Two attributions, two governments, one pattern: state operations are being named in public, with the evidence attached.

  • BleepingComputer: Turla hackers use new Cereal malware to spy on govt Exchange servers — ESET finds the Russia-aligned group’s modular .NET toolset harvesting email at government bodies in Kazakhstan and Romania
  • The Hacker News: France blames Iran for sabotage attack on refrigeration controllers at about 700 retail sites — Paris calls the October defrost attack the first purely sabotage cyber campaign on French soil

Cluster · Morning edition · Summary — Fintech Security

Stolen crypto, washed clean

Elliptic says the group behind the $6.4 billion Binance hack is laundering proceeds through disposable memecoins: six throwaway tokens on NEAR, each costing about $90 to create, moved roughly $430,000 through liquidity pools that sit between the thief wallets and the payout wallets, so blocklists alone cannot flag the money. Microsoft, meanwhile, reports an agentic framework called ARTEX that has been scanning public GitHub repositories for exposed credentials since August and turning them into Azure breaches in minutes. The laundering is small next to the $6.4 billion stolen — but the plumbing, in both cases, is built to look ordinary.

  • CybersecurityNews: North Korean hackers create fake meme coins to launder stolen funds from the $6.4B Binance hack — Elliptic traces about $430,000 through six disposable NEAR tokens
  • CybersecurityDive: Microsoft: attackers use agentic ARTEX framework to turn leaked GitHub secrets into Azure breaches in minutes — the framework has scanned public repos for exposed credentials since August

Cluster · Morning edition · Summary — Tech

The model race, repriced

Anthropic shipped Claude Fable 5.2 and Mythos 5.2, the same underlying model behind two safeguard doors: Fable, open to all, now tops the Artificial Analysis index at 65, runs up to 30% faster than 5.1, and costs 20% less — $8 per million input tokens — days before the company is expected to set its IPO price range. Meta answered the same day with Muse Ember, its smallest and cheapest model, at $0.10 per million input tokens, built for the repetitive work agents repeat all day: tool calls, coding subtasks, routing, extraction. Two launches, one direction: the frontier gets cheaper and the cheap models get closer to the frontier.

  • Reuters: Anthropic unveils new Fable, Mythos models as competition heats up ahead of IPO — Claude Fable 5.2 and Mythos 5.2 run up to 30% faster at a 20% lower price
  • Digital Trends: Meta launches Muse Ember, a cheaper AI model built for repetitive tasks — its smallest Muse model yet, at $0.10 per million input tokens, for the tool calls and extraction agents repeat all day

Cluster · Morning edition · Summary — Tech Security

The update after the update

Fireworks AI says its October incident was worse than first disclosed: a second intrusion path, through a third-party cloud provider that hosted its R&D machines, exposed account and billing information and, for a limited set of accounts, secrets, datasets and incomplete model weights — five weeks after the company first said no customer models or datasets had been touched. Apple shipped iOS 27.2.1 the same day, fixing nine flaws including an iMessage bug that could let a remote attacker join a group chat and read its messages, plus Bluetooth pairing flaws that could let a nearby device pair without any tap. Both are the same lesson in different clothes: the first disclosure is rarely the last word.

  • CybersecurityNews: Fireworks AI discloses second breach: customer billing data, datasets and partial model weights reached — a third-party cloud provider incident opened a second path into its R&D machines
  • MacRumors: Apple’s iOS 27.2.1 patches an iMessage group chat flaw and Bluetooth bugs — nine fixes in all, including a remote attacker joining group chats and reading messages

Four breaches, one morning

Attackers stole the central-login passwords of everyone registered on the Technical University of Munich's myTUM portal — including a TUMonline administrator, whose credentials were then used against the campus management system, which the university took offline and restored Monday morning with password resets. Revolve told regulators its September attack hit more than 1.5 million people, and Iris Plaza, a Japanese homeware platform, may have exposed 7.7 million customers after a cloud-service compromise forced it to pull its online store. Frontline Education told Indiana regulators its August breach affected more than 3 million school district staff and students.

  • The Register: Portal breach at Germany's top university exposes every registered user's password — attackers stole central-login passwords for all myTUM users, including a TUMonline admin, and the campus system was taken offline
  • SecurityWeek: Revolve Puts Data Breach Victim Count at 1.5 Million — Online fashion retailer Revolve has told regulators that the September cyberattack affected more than 1.5 million individuals.

Exploitation, confirmed

Hackers are now actively breaching Linux systems through the OpenSSH “ssHole” authentication bypass, CVE-2026-123158, using it to run commands, steal credentials and set up persistent access — days after the fix shipped, with SANS honeypots already logging attempts from 13 IP addresses. The same morning, CISA added a second actively exploited flaw to its catalog: CVE-2026-102895, an authentication bypass in GPUStack that gives unauthenticated attackers full administrative access, including creating persistent admin API keys, with a federal patch deadline of November 12. Both flaws share a shape — authentication that can simply be walked around — and both are already being used, not just theorized.

Cluster · Afternoon summaries · Summary — Tech Security

The tools that bite back

Fake GitHub security tools have infected more than 2,000 PCs with malware that disables defenses and steals data, Doctor Web found — a campaign that ran for two years, turning the very tools people download to stay safe into the attack. On the same day, a flaw in the APT package manager used by Debian and Ubuntu, CVE-2026-109518, was disclosed: under certain conditions it can be exploited to install a package and run code as root. The lesson of both is the same — the software you trust to protect or update your system is itself a target, and the fix in both cases is to get it from a source you can verify.

  • Cybernoz: Fake GitHub security tools infected 2,000+ PCs with malware that disables defenses and steals data, Doctor Web finds — a campaign running for two years
  • The Hacker News: Debian and Ubuntu APT flaw CVE-2026-109518 lets an attacker run code as root when installing a package under certain conditions

Cluster · Afternoon summaries · Summary — Fintech Security

A bad morning for crypto custody

A flaw in Web3Auth let an attacker drain Keplr crypto wallets set up with Google or Apple sign-in, stealing at least $1 million, per GoPlus — and Web3Auth responded by emptying other at-risk wallets into recovery itself. Separately, Ankr's Ethereum bridge lost more than $303,000 after an attacker replayed a redeemed deposit receipt to bypass withdrawal checks in five unauthorized withdrawals. And California ordered crypto ATM operator CoinFlip to pay more than $4.8 million to fraud victims, mostly elderly, after its roughly 500 ATMs failed identity checks since 2021. Three different weak points — the sign-in layer, the bridge, and the ATM — and the same outcome: money gone before anyone noticed.

  • The Hacker News: A Web3Auth flaw let an attacker drain Keplr crypto wallets set up with Google or Apple sign-in — at least $1M stolen, per GoPlus; Web3Auth emptied other at-risk wallets into recovery
  • DeFi Planet: Ankr's Ethereum bridge loses $303K+ after an attacker replays a redeemed deposit receipt to bypass withdrawal checks in five unauthorized withdrawals
  • PANews: California orders crypto ATM operator CoinFlip to pay $4.8M+ to fraud victims — mostly elderly — after its ~500 ATMs failed identity checks since 2021

Cluster · Morning edition · Summary — Fraud

Two regulators, two breach stories

The Philippines' Bureau of Internal Revenue is probing an alleged breach of more than 10 million taxpayer records, flagged by monitoring group Deep Web Konek and attributed to a threat actor calling itself Happy Go Lucky PH — but the agency has not confirmed a breach happened, and the dataset's authenticity is unverified. On the same day, the country's Securities and Exchange Commission confirmed its own breach is real: users of its online platforms had names, phone numbers, dates of birth and tax identification numbers exposed, though it says passwords were not leaked and filings were untouched. Two regulators, one day apart in tone — one investigating a claim, one notifying victims.

  • Newsbytes: The Philippines' tax bureau probes an alleged breach of 10M+ taxpayer records — flagged by a monitoring group, unconfirmed by the agency, which says it is coordinating with cybercrime authorities
  • ASTIG: The Philippines' SEC confirms a breach of its online platforms exposed users' names, phone numbers, dates of birth and tax IDs — passwords were not leaked, it says

Cluster · Morning edition · Summary — Tech Security

Exploitation outruns the patch

Zyxel's GS1900 switches were being exploited through a zero-day, CVE-2026-107441, from around August 17 — and the June patch everyone blamed the attacks on never covered it, because the exploit abused a previously unknown flaw rather than the June bug. Researchers count about 996 switches hit across 48 countries, and more than half still had factory-default credentials. The same pattern shows up in the week's other headline flaw: SANS honeypots are already recording live exploitation attempts for the OpenSSH 'ssHole' authentication bypass, CVE-2026-123158, days after the November 5 fix, with sensor evidence from November 7. In both cases the fix exists — and the attackers got there first.

  • AI Agent Update: Zyxel's June patch never stopped the GS1900 attacks — a zero-day, CVE-2026-107441, was exploited from mid-August against about 996 switches in 48 countries
  • SecurityTabs: SANS honeypots are seeing live exploitation attempts for the OpenSSH 'ssHole' auth bypass, CVE-2026-123158, days after the fix — alongside SonicWall's exploited MFA bypass and a cloud-fixed Entra privilege bug

Cluster · Morning edition · Summary — Tech

Agents everywhere, trust still catching up

DeepSeek's AI-agent platform has reached a reported 1.54 million daily users, and Mira Murati's Thinking Machines has released Inkling 2 Small, the highest-scoring open-weight model outside China — the agent era is scaling fast, and the models are getting smaller and cheaper. But the institutions are pulling back at the same time: Goldman Sachs is restricting Claude Code and GitHub Copilot to its roughly 12,000 engineers, cutting off the bankers and traders who had been using the agents to track client flows and build materials, days after a report found Claude Code's settings file had leaked secrets into nearly 2,000 public GitHub repos. Adoption and caution are arriving in the same week, from opposite directions.

  • The Neuron: DeepSeek's AI-agent platform reaches a reported 1.54M daily users as the company pushes beyond standalone models
  • KimKj: Mira Murati's Thinking Machines releases Inkling 2 Small, the highest-scoring open-weight model outside China, priced lower than rivals
  • AI Daily Grind: Goldman Sachs pulls Claude Code from its bankers and traders, limiting the AI coding assistant to engineering staff — days after a report found its settings file leaked secrets to public GitHub repos
