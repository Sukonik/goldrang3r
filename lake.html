Cluster · Afternoon summaries · Summary — Tech Security

The VPN chain, closed — on deadline day

Ivanti has now patched the last two flaws in its exploited Connect Secure chain: a privilege-escalation bug and a file-upload bug, joining October's authentication bypass, with fixed builds 25.1.1.3 and 22.8R2.6. The federal clock makes the order clear — November 2 for the escalation flaw, November 13 for the upload flaw — and the chain's lesson is to chase the fixed version number, not the CVE list, since the advisory kept growing after the first patch. Any internet-facing gateway still unpatched should be treated as suspect until its logs prove otherwise.

  • SecurityWeek: Ivanti patches two more Connect Secure zero-days chained in attacks

Spyware alerts, 99 countries deep

Apple's newest round of mercenary-spyware threat notifications reached users in 99 countries, the second major wave since August's 110-country round, taking the program past 150 countries in total. An alert means high-confidence targeting, not a confirmed infection — but Germany's federal security office still told Bundestag members to treat their phones as possibly compromised. No vendor, exploit, or operator is named, which is exactly why the code of conduct for commercial spyware vendors, due this month, matters: the alerts keep arriving faster than the accountability.

Cluster · Afternoon summaries · Summary — Tech Security

Two trust boundaries, both broken

Eighty-three malicious issues, pull requests, and comments landed on 61 public code repositories in about 45 minutes on September 1, each hiding shell commands inside HTML comments. Where a workflow pasted user-controlled text into shell code, the payload ran, encoded the environment, and tried to phone it home — with execution confirmed in at least two workflows, though no stolen secrets or altered releases have been found so far. The same week, a pre-auth flaw in the TightVNC viewer let a malicious server run code before any password prompt, by shrinking a 4 GB framebuffer into a 128 KB allocation — and its Listening Mode on port 5500 needs no password at all. Two different products, one rule: never let untrusted input reach a shell or a memory allocation unchecked.

  • Cyber Security News: Command-injection campaign hits 61 public repositories via issues and comments
  • Cyber Security News: Pre-auth remote code execution in TightVNC Viewer, fixed in 2.8.90

Cluster · Afternoon summaries · Summary — Tech Security

The 27-million-record claim from Tashkent

A hacking collective calling itself Butterfly claims it breached a database holding personal records of more than 27 million Uzbek citizens — names, phone numbers, national ID numbers, home addresses, passport details, and biometric photos — leaking a minister's details as proof and threatening a dark-web sale if demands, still undisclosed, were not met by the morning of November 2. The claim is unverified, and it lands on top of earlier reports of a leak from a traffic-safety platform plus a developer's disclosure of a ministry portal flaw said to expose tens of millions of records. Uzbekistan's Interior Ministry and its Cybersecurity Center have opened an inquiry; until they confirm scope, this stays a claim with a very large blast radius, not a confirmed breach.

  • Fergana News: Hackers claim massive breach of personal data of 27 million Uzbek citizens

Pull the plug: the wallet drain

BTCPay Server, built so no central party can pull the plug, had to ask every operator to pull it themselves: shut down until the investigation ends. Cluster · Morning edition

The viewer that trusts the server

TightVNC's viewer computes its framebuffer in 64 bits but stores it in a 32-bit int, so a server announcing 32768 x 32769 pixels gets a 128 KB buffer for 4 GB of pixels — and pixel writes then land at attacker-chosen offsets. A public PoC chains an ASLR leak and a ROP chain to CreateProcessW, before any password prompt, and Listening Mode on port 5500 needs no password at all. The fix shipped quietly in 2.8.89 and 2.8.90; upgrade to 2.8.90.

  • Cyber Security News: A pre-auth RCE in TightVNC Viewer 2.8.88 lets a malicious server execute code before any password prompt, via a 32-bit integer wrap that turns a 4 GB framebuffer into a 128 KB allocation; fixed in 2.8.89 and 2.8.90
